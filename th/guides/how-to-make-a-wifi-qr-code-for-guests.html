วิธีสร้าง QR Code Wi-Fi ให้แขกของคุณ

การพิมพ์รหัส Wi-Fi ยาว ๆ บนโทรศัพท์ช้าและพิมพ์ผิดง่าย QR code ให้แขกเล็งกล้องแล้วเชื่อมต่อได้ในไม่กี่แตะ

ขั้นตอน

  1. เปิดเครื่องมือ Wi-Fi QR Code
  2. ใส่ชื่อเครือข่าย (SSID) ให้ตรงตามที่แสดง รวมถึงตัวพิมพ์ใหญ่
  3. เลือกประเภทความปลอดภัย (ปกติคือ WPA/WPA2) และใส่รหัสผ่าน
  4. ดาวน์โหลดรูปภาพแล้วพิมพ์ หรือวางบนการ์ด

วางไว้ที่ไหน

  • ใกล้ทางเข้า บนตู้เย็น หรือที่เคาน์เตอร์ต้อนรับ
  • ในประกาศเช่าที่พักหรือแฟ้มต้อนรับ
  • พิมพ์ให้ใหญ่พอที่จะสแกนได้จากระยะประมาณ 30 ซม.

รักษาความปลอดภัย

ใครเห็นโค้ดก็เข้าเครือข่ายได้ ลองใช้เครือข่ายแขกแยกต่างหากถ้าเราเตอร์รองรับ และเปลี่ยนรหัสผ่านถ้าโค้ดที่พิมพ์ไว้หาย โค้ดถูกสร้างในเบราว์เซอร์ของคุณ รหัสผ่านไม่ถูกส่งไปยังเซิร์ฟเวอร์ใด ๆ

สำหรับลิงก์ ข้อมูลติดต่อ หรือข้อความอื่น ใช้ QR Code Generator เต็มรูปแบบ (หน้าเครื่องมือเป็นภาษาอังกฤษ)
