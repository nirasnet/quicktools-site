เริ่มจากศูนย์: ลง AI ผู้ช่วยในคอม (มีตัวเริ่มฟรี)

บทความชุดนี้มาจากเพจ จับมือ AI ที่สอนให้คนทั่วไปใช้ AI ทำของใช้ได้จริงทีละขั้นตอน โดยไม่ต้องเขียนโค้ด ติดตามได้ทาง Facebook YouTube และ TikTok

หลายคนติดตั้งแต่ขั้นแรก บทความนี้จึงมาก่อนโปรเจกต์อื่น ผู้ช่วยทั้ง 3 ตัวด้านล่างเป็นแอปบน Mac หรือ Windows กดดาวน์โหลด ล็อกอิน แล้วเริ่มใช้ได้เลย ไม่ต้องเปิด Terminal และไม่ต้องเขียนโค้ดเป็น

ตัวที่ 1: Codex (ของ ChatGPT)

เริ่มได้ด้วยบัญชี ChatGPT ฟรี ไปที่ chatgpt.com/codex กดดาวน์โหลด แล้วล็อกอิน

ตัวที่ 2: Antigravity (ของ Google)

แผนบุคคลใช้ฟรี ณ ตอนที่เขียน ล็อกอินด้วย Gmail ดาวน์โหลดที่ antigravity.google มีทั้ง Mac, Windows และ Linux

ตัวที่ 3: Claude Code (ของ Anthropic)

ตัวนี้ผู้ทำใช้ประจำ เก่งงานยาว ๆ ต้องสมัครแผน Pro (ประมาณ 17-20 ดอลลาร์สหรัฐต่อเดือน ตามที่เขียนไว้ตอนนั้น) ดูรายละเอียดที่ claude.com/product/claude-code มือใหม่แนะนำลองตัวฟรีก่อน ติดใจค่อยอัปเกรด

ราคาและสิทธิ์ใช้ฟรีเปลี่ยนได้ ข้อมูลข้างต้นตรวจเมื่อ ต.ค. 2026 ควรเช็กจากหน้าทางการของแต่ละตัวอีกครั้งก่อนสมัคร

สั่งงานครั้งแรก

  1. ติดตั้งเสร็จ เลือกโฟลเดอร์งานเมื่อแอปถาม
  2. พิมพ์สั่งเป็นภาษาธรรมดา เช่น "ทำเว็บนับถอยหลังวันเกิดลูกให้หน่อย"
  3. ถ้า AI ขออนุญาตก่อนทำอะไร ให้อ่านก่อนแล้วค่อยกดยืนยัน

แค่นี้ก็พร้อมทำโปรเจกต์ต่อไป: เกมทายศัพท์อังกฤษให้ลูก และ โหมดเด็กบนทีวี Android ไม่แน่ใจว่าจะเขียนคำสั่งอย่างไร อ่าน 5 เทคนิคสั่ง AI
