สั่ง AI ทำแอปล็อกทีวีที่บ้านจาก iPhone: เรื่องจริงของ Peach TV

เล่าวิธีสร้าง Peach TV แอป iPhone คุมทีวี Android ที่บ้าน (โหมดเด็ก จำกัดเวลา ล็อกจอ) ด้วย AI พร้อม prompt จริง สิ่งที่พลาด และเรื่องที่ยังไม่จบ

โดย 9M4ck · มือใหม่

สิ่งที่คุณจะได้

  • prompt จริงตั้งแต่คุมทีวีจากนอกบ้านจนถึงโหมดเด็ก
  • ทำยังไงให้คนในบ้านใช้ได้ โดยไม่ต้องตั้ง VPN เอง
  • เรื่องที่ยังไม่จบ คือปลุกทีวีจากโหมดหลับลึก
ในหน้านี้ก่อนเริ่ม: ทีวีสะอาดแล้ว แต่ยังไม่ใช่ของเราขั้นที่ 1: อยากคุมจากนอกบ้านขั้นที่ 2: แอป iPhone จาก prompt เดียวขั้นที่ 3: ใส่กฎของบ้านลงไปขั้นที่ 4: โหมดเด็กขั้นที่ 5: ให้คนที่บ้านใช้ได้ โดยไม่ต้องตั้ง VPN เองขั้นที่ 6: ส่งให้ภรรยาลองผ่าน TestFlightขั้นที่ 7: ปัญหาที่ยังไม่จบ คือปลุกทีวีหลังจากนั้น: ใช้ไปเรื่อยๆ ก็ขอเพิ่มไปเรื่อยๆPrompt ที่ใช้ (พิมพ์จริง รวมคำสะกดผิด)

เรื่องนี้ต่อจากตอนที่ผมล้างหน้าโฮมทีวี Android ที่บ้านด้วย CleanYourTV (อ่านได้ใน บทความล้างทีวี) พอทีวีสะอาดแล้ว ก็มีคำถามตามมาเอง ว่าจะทำยังไงให้ลูกดูแต่สิ่งที่ควรดู โดยไม่ต้องมีใครยืนเฝ้าหน้าทีวี ผมเลยเปิดแชทกับ AI ยาวๆ หนึ่งแชท ระหว่างวันที่ 23 ถึง 25 ตุลาคม และสั่งมันทีละเรื่อง จนได้แอป Peach TV ที่คุมทีวีจาก iPhone

บทความนี้เล่าเฉพาะ "ขั้นตอนสร้าง" กับ prompt ที่ผมพิมพ์จริง ส่วนหน้าตาโหมดเด็กและวิธีตั้งค่าที่บ้าน อ่านได้ที่ บทความตั้งโหมดเด็กและเวลาดูทีวี

โค้ดและ prompt บน GitHubหน้าเว็บของแอป

สถานะ ตอนที่เขียนบทความนี้ ผมค้นหา Peach TV ใน App Store แล้วไม่เจอ จึงยังไม่ใส่ลิงก์ดาวน์โหลด ที่บ้านผมแชร์ให้ครอบครัวผ่าน TestFlight ถ้าขึ้นสโตร์แล้วจะกลับมาเพิ่มลิงก์ที่นี่

ก่อนเริ่ม: ทีวีสะอาดแล้ว แต่ยังไม่ใช่ของเรา

ผมสั่ง AI ให้ทำตาม CleanYourTV ของ Gathin ปิดโฆษณา ปิดแอปขยะ และใส่หน้าโฮมแบบ Apple TV พร้อมธีมสีพีชของบ้านเรา ("Look Peach Family") จากนั้นผมก็บ่นไปว่า

ที่เห็นคือ screensaver ของ Google ที่มีโฆษณา มันเลยเปลี่ยนเป็นนาฬิกาของ launcher แล้วอีกเรื่องที่งงคือหน้าโฮมเก่ากลับมาเอง สุดท้ายเป็นเพราะแอปตัวติดตั้งจำ Wi-Fi ไว้ พอทีวีต่อ Wi-Fi ใหม่ หน้าโฮมใหม่ก็อยู่ถาวร

ขั้นที่ 1: อยากคุมจากนอกบ้าน

ปัญหาแรกที่ผมนึกออกคือ ถ้าอยู่นอกบ้านก็คุมทีวีไม่ได้ เพราะทีวีอยู่ใน LAN ผมเลยถามตรงๆ ว่าใช้ VPN อย่าง Tailscale ได้ไหม แล้วสั่งให้ติดตั้งให้เลย

AI ติดตั้ง Tailscale บนทีวีแล้วตั้งให้เป็น VPN แบบเปิดตลอด ทีวีจึงเข้าถึงได้จากเครือข่ายส่วนตัวของครอบครัวทุกที่

ขั้นที่ 2: แอป iPhone จาก prompt เดียว

make tv remote app for my ip17pro which auto check is tv is online and close or lock it or snap screen

prompt เดียวนี้ได้สองชิ้น ชิ้นแรกคือ tv-agent บริการเล็กๆ บนทีวี (Android accessibility service ที่มี HTTP API ป้องกันด้วย token) ชิ้นที่สองคือแอป SwiftUI บน iPhone ที่เช็กทีวีทุกไม่กี่วินาที แล้วสั่งล็อก ปิด ส่งข้อความ หรือจับภาพหน้าจอได้

ใช้ได้ไม่นานก็เจอจุดอ่อน ล็อกครั้งแรกกดรีโมทข้ามได้ AI เลยเขียนหน้าจอล็อกใหม่ให้ดักทุกปุ่ม

ขั้นที่ 4: โหมดเด็ก

ผมอยากให้บัญชีเด็กของ Google TV เป็นค่าเริ่มต้น แต่ตัวสลับโปรไฟล์อยู่ใน launcher เดิมที่ผมปิดไปแล้ว AI ลองทางเลี่ยงหลายแบบ ไม่มีแบบไหนสะอาด มันเลยหยุดแล้วบอกตรงๆ ผมจึงเปลี่ยนวิธีคิด

ผลคือทีวีเป็นโหมดเด็กเป็นค่าเริ่มต้น หน้าโฮมโชว์เฉพาะแอปที่อนุญาต ถ้าเปิดแอปอื่นจะถูกส่งกลับหน้าโฮม และแอป iPhone มีปุ่มสลับ Kids/Parent กับตัวแก้รายการแอป พอทีวีดับจะกลับเป็นโหมดเด็กเอง

ขั้นที่ 5: ให้คนที่บ้านใช้ได้ โดยไม่ต้องตั้ง VPN เอง

ผมพิมพ์ถามว่า

next i want to consult when we outside home without same wifi it need to use tailscale ,  but non technical
from my wife it hard to config it it many step,  can we do something one stop service build it of this project

AI เสนอสามทาง คือ A แชร์ทีวีให้เข้าบัญชี Tailscale ของเธอ B ฝัง Tailscale ไว้ในแอป และ C ใช้ cloud relay ผมเลือก B โดยส่งกุญแจเป็นลิงก์เชิญแทนที่จะฝังไว้ในแอป ตอนนี้ libtailscale อยู่ในแอป iPhone เลย ไม่ต้องมีแอป VPN แยก ผู้ปกครองกด "เชิญครอบครัว" ส่งลิงก์ทาง LINE อีกคนกดครั้งเดียวก็จบ และตั้งกฎให้โทรศัพท์เข้าถึงได้เฉพาะพอร์ตของทีวี

ส่วนที่ผมต้องทำเองคือกดตั้งค่าในหน้า admin ของ Tailscale ทีละขั้นตามที่ AI เขียนให้ แล้วให้มันตรวจว่าทีวีกับโทรศัพท์มีแท็กถูกและเข้าถึงกันได้

ขั้นที่ 6: ส่งให้ภรรยาลองผ่าน TestFlight

AI ตั้งแอปใน App Store Connect อัปโหลดบิลด์ และเชิญเธอเป็นผู้ทดสอบ TestFlight สคริปต์อยู่ในโฟลเดอร์ ios/scripts ของ repo (ผมไม่ใส่อีเมลของใครไว้ใน prompt ที่เผยแพร่)

ขั้นที่ 7: ปัญหาที่ยังไม่จบ คือปลุกทีวี

why google tv can use remote to open tv from standby mode but our app cannot wake screen on

ผมให้ AI ใช้เครื่องมือวิเคราะห์แพ็กเก็ตจากรีโมท Google TV มาดู ข้อสรุปในเอกสารของ repo คือการกดปุ่มเปิดปลุกทีวีได้จริง แต่กฎจำกัดเวลาของแอปเองกลับสั่งให้ทีวีหลับต่อทันที ส่วนตอนอยู่ในโหมดหลับลึก ไม่มีอะไรบนเครือข่ายปลุกทีวีเครื่องนี้ได้เลย แม้แต่ Wake-on-LAN ใน git มี commit ชื่อ "agent 1.8: wake from sleep" ตามมาในวันที่ 26 ตุลาคม แต่ผมไม่ได้เขียนว่ามันแก้ได้หมด

หลังจากนั้น: ใช้ไปเรื่อยๆ ก็ขอเพิ่มไปเรื่อยๆ

  • 26 ต.ค. ต่อยอดให้ใช้กับทีวีเครื่องอื่นได้ (agent 2.0 มีการจับคู่ ตัวติดตั้ง ADB ในแอป และรองรับหลายทีวี) แล้วเตรียมเอกสารสำหรับเผยแพร่
  • 3 พ.ย. แก้ให้เพิ่มเวลาได้ทีละ 5 และ 10 นาที จากเดิมที่เลือกได้แค่ 15, 30, 45, 60
  • 14-15 พ.ย. เพิ่มเพลย์ลิสต์ YouTube ที่พ่อแม่คัดเอง ให้เด็กเลือกดูได้เฉพาะในลิสต์ ผมสั่งไว้ว่า "goal is don't want kid to playand clip on you tube without list from parent" แล้วทำแอป Playlist บนทีวี
  • 15 พ.ย. สั่งให้ปรับ AIS PLAY ที่โหลดนานให้โชว์เฉพาะช่องเด็ก 201-206
ทำด้วย AI ส่วนสร้างแอปในบทความนี้ ตามบันทึกใน repo ของผม ทำด้วย GitHub Copilot CLI (Claude Opus 5.5) ส่วนฟีเจอร์รอบเดือนพฤศจิกายนทำใน Claude Code ผมเป็นคนบอกว่าอยากได้อะไร ตัดสินใจเรื่องกฎของบ้าน และลองกับทีวีกับ iPhone จริง ระวังเรื่องข้อมูล: ผมตัด IP ของบ้าน token รหัสปลดล็อก และอีเมลออกจากทุกอย่างที่เผยแพร่

เกี่ยวกับผู้เขียน
