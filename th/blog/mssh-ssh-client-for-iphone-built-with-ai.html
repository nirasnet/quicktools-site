ทำแอป SSH บนมือถือด้วย AI แล้วพิมพ์ไทยแล้วค้าง: เรื่องจริงของ mSSH

เล่าวิธีสร้าง mSSH แอป SSH และ SFTP ฟรีบน iPhone, iPad และ Mac ด้วย Claude Code บั๊กคีย์บอร์ดภาษาไทย แครชจาก iCloud prompt และลิงก์ App Store

โดย 9M4ck · มือใหม่

สิ่งที่คุณจะได้

  • จากโปรเจกต์เปล่าเป็นแอป SSH ที่ใช้งานได้ในวันเดียว
  • บั๊กคีย์บอร์ดภาษาไทยที่ทำให้เทอร์มินัลค้าง และวิธีแก้
  • prompt ที่เขียนใหม่จากฟีเจอร์จริง พร้อมลิงก์ App Store และ GitHub
ในหน้านี้วันเดียว ได้แอปที่ต่อ server ได้บั๊กที่เจอเพราะผมพิมพ์ภาษาไทยส่งขึ้นสโตร์ และต่อด้วย Mac กับหน้าจอแยกซิงก์ iCloud ทำเอาแอปแครชTip jar และรุ่นที่ต้องเปลี่ยนเลขใหม่prompt (เขียนใหม่จากฟีเจอร์จริง)

mSSH คือแอป SSH และ SFTP สำหรับ iPhone, iPad และ Mac ผมให้ Claude Code เป็นคนเขียน แล้วส่งขึ้น App Store เป็นแอปฟรีที่ไม่มีโฆษณา ไม่เก็บข้อมูลการใช้งาน และเปิดซอร์สโค้ดไว้ใน GitHub ด้วย

โหลด mSSH บน App Storeโค้ดบน GitHub

ก่อนอ่าน ผมหาแชทเก่าที่สั่ง Claude Code ตอนเริ่มทำ mSSH ไม่เจอแล้ว บทความนี้เล่าตามประวัติ commit และเอกสารที่ Claude เขียนไว้ในโปรเจกต์ และ prompt ท้ายบทความผมเขียนใหม่จากฟีเจอร์จริง ไม่ใช่ข้อความต้นฉบับ ผมบอกไว้ตรงนั้นอีกครั้ง

วันเดียว ได้แอปที่ต่อ server ได้

ตามประวัติใน Git วันที่ 30 มีนาคม เป็นวันเริ่มโปรเจกต์ ตอนสองทุ่มครึ่งเป็นโครงเปล่าที่ใช้ไลบรารี SwiftTerm ทำหน้าจอเทอร์มินัล และ Citadel ทำ SSH ก่อนสามทุ่มครึ่งมีฟีเจอร์หลักครบ ได้แก่ SFTP, การยืนยัน host key แบบ TOFU (เชื่อกุญแจเครื่องปลายทางตอนต่อครั้งแรก แล้วเตือนถ้ามันเปลี่ยน), ซิงก์ iCloud, ปลดล็อกด้วย Face ID และนำเข้า SSH key คืนนั้นเองมันก็ติดตั้งลง iPhone ผมแล้ว วันที่ 31 ใส่ไอคอนและแก้เรื่องคีย์บอร์ดกับการเชื่อมต่อ

ผมไม่ได้เขียนโค้ดเหล่านี้เอง Claude Code เขียนทั้งหมด และมันเซ็น Co-Authored-By ใน commit ไว้ให้ 34 ครั้งจากทั้งหมด 35 ครั้ง ผมใช้เวลาไปกับการลองบนเครื่องจริงมากกว่า

บั๊กที่เจอเพราะผมพิมพ์ภาษาไทย

รายงานการแก้บั๊กรุ่น 1.0.1 ลงวันที่ 2 เมษายน มีสองตัว และตัวแรกเป็นแบบที่คนที่ไม่ได้พิมพ์ภาษาไทยคงไม่เจอ พอสลับเป็นคีย์บอร์ดไทยแล้วพิมพ์ไปหนึ่งสองตัวอักษร เทอร์มินัลค้างเลย สาเหตุที่ Claude หาเจอคือ ทุกการกดแป้นถูกส่งไปเขียนลงช่อง SSH แบบแยกกัน แต่ช่องนั้นไม่ได้ออกแบบมาให้หลายงานเขียนพร้อมกัน ตัวอักษรภาษาไทยหนึ่งตัวใช้สามไบต์ และระบบพิมพ์ภาษาไทยของ iOS ยิงเหตุการณ์ถี่กว่าภาษาอังกฤษ การเขียนจึงชนกัน ตัวแก้คือต่อคิวให้ทุกการเขียนไหลผ่านทางเดียวและทำทีละอัน

บั๊กที่สองคือหน้าจอขาวหลังปัดแอปทิ้ง ซึ่งเกิดบ่อยหลังจากค้างเพราะบั๊กแรก เรื่องนี้ทำให้ผมรู้ว่าต้องทดสอบแอปด้วยภาษาที่ตัวเองใช้จริง ไม่ใช่แค่ภาษาอังกฤษ

ส่งขึ้นสโตร์ และต่อด้วย Mac กับหน้าจอแยก

วันที่ 5 เมษายนเป็นรุ่น 1.1.0 มีหน้าจอแบ่งสองส่วนแบบ iTerm2, แอป Mac แบบเนทีฟ และที่น่าสนใจที่สุดคือปุ่มเปิด Claude Code ในหน้าต่างแยก ทำให้สั่ง AI ให้ทำงานบน server ได้จากโทรศัพท์ บิลด์ 3, 4 และ 5 ถูกส่งขึ้น App Store Connect ในสองวันนั้น โดยบิลด์ 4 ต้องแก้คำตอบเรื่อง export compliance (การส่งออกเทคโนโลยีเข้ารหัส) ให้ถูก

ซิงก์ iCloud ทำเอาแอปแครช

ผมอยากให้ข้อมูลเชื่อมต่อซิงก์ระหว่างเครื่อง ตอนแรกเปิด CloudKit แล้วแอปแครชบนเครื่องจริง ต้องแก้สองรอบในวันที่ 6 เมษายน (เอาข้อกำหนด unique ออกจากโมเดลข้อมูล แล้วปิดซิงก์ไว้ก่อน) พอถึงกลางเดือนผมตั้งเป้าให้ใกล้เคียงแอป Termius แล้วทำซิงก์ใหม่ทั้งชุด รวมถึงตัวเลือกให้ซิงก์ private key ผ่าน iCloud Keychain ที่เข้ารหัสต้นทางถึงปลายทาง ซึ่งผู้ใช้เลือกเปิดเป็นรายคีย์ได้ ไม่ได้เปิดให้โดยอัตโนมัติ

บน Mac ยังเจอแครชจากเลย์เอาต์ ต้องปิด CloudKit บน macOS แล้วใช้การซิงก์แบบง่ายกว่าแทน ข้อสรุปของผมคือ ถ้าให้ AI ทำเร็วๆ มันอาจเริ่มจากวิธีที่ซับซ้อน แล้วเราต้องถอยกลับมาหาวิธีที่ง่ายกว่าเมื่อเจอปัญหาจริงบนเครื่อง

Tip jar และรุ่นที่ต้องเปลี่ยนเลขใหม่

กลางเดือนเมษายนผมเพิ่ม tip jar ผู้ใช้เลี้ยงกาแฟได้ในราคา $0.99, $4.99 หรือ $9.99 ไม่มีฟีเจอร์ไหนถูกล็อกไว้ ตอนจะส่ง 1.2.0 อีกรอบ เวอร์ชันนั้นถูกปิดรับบิลด์ใหม่แล้ว ผมเลยต้องขึ้นเป็น 1.2.1 และ 1.2.2 แทน

ทำด้วย AI โค้ดเขียนโดย Claude Code ผมเป็นคนกำหนดทิศทาง ทดสอบบนมือถือและ Mac ของตัวเอง ตัดสินใจเรื่องขอบเขต และเป็นคนส่งขึ้น App Store

prompt (เขียนใหม่จากฟีเจอร์จริง)

ผมหาแชทเริ่มต้นไม่เจอ ข้อความต่อไปนี้จึงเป็นสิ่งที่ผมจะพิมพ์ถ้าเริ่มวันนี้ โดยเรียงจากฟีเจอร์ที่อยู่ในแอปจริงและเงื่อนไขที่เรียนรู้มาตอนทำ ถ้านำไปใช้ ปรับรายการฟีเจอร์ให้ตรงกับที่ต้องการ

1. สร้างแอปตั้งต้น

Build an SSH and SFTP client for iPhone, iPad and Mac in Swift and SwiftUI (iOS 18+, macOS 15+).
- Terminal: use SwiftTerm for xterm-256color emulation; use Citadel for SSH.
- Connections: save hosts with groups, favorites and color tags; quick connect bar that accepts user@host:port.
- Auth: password, and OpenSSH keys (Ed25519, ECDSA, RSA). Generate Ed25519 keys inside the app. Keep secrets in the Keychain only.
- Host key: trust on first use (TOFU), show the SHA-256 fingerprint, warn loudly if it changes.
- SFTP: browse, upload, download, delete.
- Lock the app behind Face ID / Touch ID if the user turns it on.
Constraints: no analytics, no ads, no third-party tracking. Everything stays on the device unless the user turns on sync.
Ask me before choosing a library that is not in the list above.

2. เรื่องที่ควรสั่งเพิ่มทันที

Test typing with the Thai keyboard (and any other IME). Characters can arrive in rapid bursts. Make sure every write to the SSH channel goes through one serial queue, never from concurrent tasks.
Also make sure the app never crashes at launch if the local database cannot open: show a recovery screen instead of a blank screen.

3. ซิงก์ข้ามเครื่อง

Add optional iCloud sync for connections, snippets and key metadata across iPhone, iPad and Mac.
Private keys must sync only if the user turns it on for that specific key, and only through end-to-end encrypted iCloud Keychain.
If CloudKit causes crashes on a platform, fall back to key-value sync and tell me what you changed.

4. ส่งขึ้นสโตร์

Prepare the app for the App Store: privacy policy page, screenshots, release notes and the export compliance answers. Add an optional tip jar with three consumable tips and make sure nothing is locked behind payment. Do not reuse a version number that has already been uploaded.
ข้อควรระวัง อย่าวางรหัสผ่านหรือ private key ลงในแชทกับ AI ถ้าจำเป็นต้องให้มันทดสอบการเชื่อมต่อ ให้ใช้ server ทดสอบกับคีย์ที่ใช้ครั้งเดียว แล้วลบทิ้งหลังจบ

เกี่ยวกับผู้เขียน

สวัสดีครับ ผม 9M4ck เป็นคุณพ่อที่ชอบลองของใหม่ โดยเฉพาะ AI ที่แค่พิมพ์บอกเป็นภาษาบ้าน ๆ แล้วมันทำของใช้ได้จริงให้ ผมไม่ได้เขียนโค้ดเอง ผมเปิดเพจ จับมือ AI เพราะเพื่อน ๆ ทักมาขอให้จับมือทำของที่ผมทำที่บ้าน เช่นทีวีของครอบครัว

ภาพถ่ายและภาพหน้าจอในบทความมาจากทีวี โทรศัพท์ และโปรเจกต์ของผมเอง ส่วนคลิปและเสียงบรรยายบน Facebook ทำด้วยเครื่องมือ AI บล็อกนี้เรียบเรียงขั้นตอนที่เป็นตัวหนังสือจากโพสต์ของผม ให้ทำตามได้ตามจังหวะของคุณ
