ตั้งโหมดเด็กและกฎเวลาดูทีวีบน Android TV ด้วย AI

บทความชุดนี้มาจากเพจ จับมือ AI ที่สอนให้คนทั่วไปใช้ AI ทำของใช้ได้จริงทีละขั้นตอน โดยไม่ต้องเขียนโค้ด ติดตามได้ทาง Facebook YouTube และ TikTok

ลูกแอบเปิดแอปอื่นและดูเพลินจนเลยเวลานอน เป็นปัญหาที่หลายบ้านเจอ คู่มือนี้ตามการตั้งค่าจริงที่บ้าน โดยให้ผู้ช่วย AI ทำงานทางเทคนิคบนทีวี Android TV หรือ Google TV ส่วนคุณตอบคำถามง่าย ๆ ไม่กี่ข้อ ผู้ทำไม่ได้เขียนโค้ดเองสักบรรทัด และภาพหน้าจอในคลิปต้นฉบับเป็นของทีวีที่บ้านจริง

สิ่งที่ได้

  • หน้าโฮมของลูกที่มีแต่แอปที่คุณอนุญาต ไม่มีอะไรล่อตา
  • ช่วงเวลาดูทีวีที่คุณกำหนด เช่น วันเรียน 07:00-07:15 และ 17:00-20:30 เสาร์-อาทิตย์ 07:00-20:30
  • หมดเวลาทีวีล็อกเองและเสียงเงียบ ไม่ต้องเถียงกับลูก
  • ถ้ามี Mac และ iPhone จะได้แอปสั่งล็อกทีวี สลับโหมด และดูประวัติการดูได้ (ไม่บังคับ)

เตรียมของ

  • ใช้ได้กับ Android TV หรือ Google TV (เช่น TCL, Sony, Xiaomi, Hisense, Chromecast) ใช้ไม่ได้กับ Samsung, LG และ Fire TV
  • คอม Mac หรือ Windows ที่ต่อ Wi-Fi วงเดียวกับทีวี
  • ผู้ช่วย AI ที่รันคำสั่งบนเครื่องได้ เช่น Claude Code, GitHub Copilot CLI, Codex หรือ Gemini CLI

ขั้นตอน

  1. เปิดโหมดนักพัฒนาที่ทีวี ไปที่ การตั้งค่า › ระบบ › เกี่ยวกับ แล้วกด OK ที่บิลด์ของระบบปฏิบัติการ Android TV 7 ครั้ง
  2. เปิด USB debugging ในเมนูตัวเลือกสำหรับนักพัฒนาแอปที่เพิ่งขึ้นมา
  3. ล้างทีวีก่อน เปิดผู้ช่วย AI แล้วแปะ prompt แรกด้านล่าง ซึ่งใช้โปรเจกต์โอเพนซอร์ส CleanYourTV ปิดโฆษณาและแอปขยะ ไม่มีการลบแอปทิ้งถาวร สั่งให้ AI restore กลับได้
  4. อนุญาตคอมพิวเตอร์ เมื่อทีวีถาม แล้วตอบคำถามของ AI
  5. เพิ่มโหมดเด็ก โดยแปะ prompt ที่สองในแชทเดิม AI จะถามว่าลูกเปิดแอปไหนได้ และทีวีใช้ได้ช่วงเวลาไหน

prompt 1: ล้างทีวี

Talk to me in Thai. Clone https://github.com/Gathin23/cleanyourtv and work inside that folder.
Open its PROMPT.md and do everything between the two --- lines, exactly as if I had pasted it to you.
My TV model is: ____ (if I left this blank, read the model from the TV once you are connected).

prompt 2: โหมดเด็กและกฎเวลา

Talk to me in Thai. My TV was cleaned with CleanYourTV and the cleanyourtv folder is on this computer.
Clone https://github.com/nirasnet/peach-tv next to that folder, read its README.md, and set up the family TV
on my real TV step by step, checking each step with a screenshot from the TV:
1. Install the TV agent with tv-agent/install.sh. If network ADB is already closed, tell me how to turn
   USB debugging back on, and close it again at the end. Keep the agent token private, don't print it in chat.
2. Ask me which apps my kids may open, then turn on Kids mode with only those apps.
3. Ask me what hours the TV may be used on school days and on weekends, and the daily screen-time limit,
   then set those rules.
4. Show me the unlock code and how to unlock the lock screen with the remote.
5. Ask me whether I have a Mac with Xcode and an iPhone. If yes, build and install the Peach TV app
   (ios/build-and-install.sh) and pair it with the TV. If not, give me a small script to lock and unlock
   the TV from this computer.
Ask me before anything that needs my Apple account. Skip "away from home" (Tailscale) unless I ask for it.

prompt เป็นภาษาอังกฤษเพื่อให้ AI ทำงานแม่นที่สุด แต่สั่งให้ AI คุยกับเราเป็นภาษาไทย ข้อความเต็มและฉบับล่าสุดอยู่ที่ repository peach-tv

ข้อควรระวังด้านความปลอดภัย

  • โหมดนักพัฒนาและ USB debugging ให้คอมควบคุมทีวีได้ลึก ปิด USB debugging อีกครั้งเมื่อเสร็จ ตามที่ prompt สั่ง
  • เก็บโทเคนเข้าถึงเป็นความลับ อย่าวางในแชท
  • ใช้กับทีวีของคุณเองเท่านั้น และอ่านแผนของ AI ก่อนกดอนุญาต
