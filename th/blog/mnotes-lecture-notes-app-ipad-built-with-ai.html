สั่ง AI ทำแอปจดโน้ตแบบ GoodNotes แล้วถอดเสียงหายครึ่งทาง: เรื่องจริงของ mnotes

เล่าวิธีสร้าง mnotes แอปจดโน้ตบน iPad และ iPhone ที่อัดเสียง ถอดเสียง และสรุปได้ ด้วย Claude Code พร้อม prompt จริง บั๊กที่เจอ และขั้นตอนส่งขึ้น App Store

โดย 9M4ck · มือใหม่

สิ่งที่คุณจะได้

  • จากประโยคเดียวเป็นแอป iPad ที่ใช้งานได้
  • บั๊กจริงสามเรื่อง ถอดเสียงเหลือ 10 วินาที โลโก้ทับปุ่ม และซิงก์ไม่ไป
  • prompt ทุกตัวที่พิมพ์จริง ตัดข้อมูลส่วนตัวออกแล้ว
ในหน้านี้คำสั่งแรก ขอทุกอย่างในประโยคเดียวสองสัปดาห์ต่อมา กลับมาสั่งให้ "เก่งขึ้น"ส่งขึ้น App Store ให้ AI ทำทั้งกระบวนการหลังจากนั้นprompt ที่ผมใช้จริง

เรื่องนี้เริ่มจากคำสั่งบรรทัดเดียวที่ผมพิมพ์ใส่ Claude Code ว่าอยากได้แอปจดโน้ตบน iPad แบบ GoodNotes ที่ถ่ายรูปสไลด์ได้ อัดเสียงได้ แล้วถอดเสียงเป็นข้อความ สรุป และแชร์ต่อได้ ตั้งชื่อว่า mnotes ย่อมาจาก Minimal notes ผมไม่ได้เขียนโค้ดเองสักบรรทัด

เหตุผลที่ผมอยากได้แอปนี้ ผมไม่ได้เขียนไว้ในแชทตรงไหนเลย ที่เห็นในคำสั่งแรกคือคำว่า lecture กับ GoodNotes ผมเลยเล่าเท่าที่มีหลักฐาน คือสิ่งที่พิมพ์ไปจริง สิ่งที่พัง และสิ่งที่แก้

หน้าเว็บของแอป mnotes

เรื่องลิงก์ App Store ผมลองค้นชื่อ mnotes ใน App Store แล้วยังหาหน้าแอปสาธารณะไม่เจอ เลยยังไม่ใส่ลิงก์โหลด ถ้าขึ้นสโตร์เมื่อไรจะมาเติมให้

คำสั่งแรก ขอทุกอย่างในประโยคเดียว

วันที่ 30 ก.ย. ผมพิมพ์ยาวเป็นภาษาอังกฤษสำเนียงผม ขอ "ux ui awesome, logo, พร้อมส่งขึ้น App Store" มาในประโยคเดียวกัน ไม่มีสเปก ไม่มีแผนผัง อีกสองวันต่อมาก็สั่งว่า deploy ลง iPad ของผม แล้วผมก็ได้ลองใช้จริง

ส่วนที่ผมชอบคือผมไม่ต้องรู้ว่า PencilKit กับ SwiftData คืออะไร รู้แค่ว่าอยากให้เขียนด้วย Apple Pencil ได้ ถ้าอยากรู้ชื่อเทคโนโลยี ผมเปิดไฟล์ README ที่ Claude เขียนไว้ดูทีหลังได้

สองสัปดาห์ต่อมา กลับมาสั่งให้ "เก่งขึ้น"

ผมกลับมาที่โปรเจกต์นี้อีกครั้งวันที่ 14 ต.ค. และพิมพ์ว่าอยากได้ฟีเจอร์ที่ใช้งานดีและ UX สวยกว่าเดิม แล้วให้ลงทั้ง iPhone และ iPad ไปพร้อมกัน จากนั้นก็เป็นรอบของ "ลองใช้ เจอปัญหา สั่งแก้" วนไปเรื่อยๆ ผมเลือกเล่าสามเรื่องที่จำได้ชัดจากแชท

1. อัดเสียงแล้วถอดเสียงได้แค่ 10 วินาทีสุดท้าย

ผมทดสอบอัดเสียงประมาณ 27 วินาที แล้วถอดเสียงออกมาแค่ 10 วินาทีท้าย ผมพิมพ์ไปว่า "is bug please check and fix it" วันรุ่งขึ้นบน iPad ก็ยังเป็นอีก และตอนกด "ถอดเสียงใหม่" ข้อความเดิมที่มีก็หายไปด้วย ผมแจ้งซ้ำสามรอบในสองวัน

จากโน้ตที่ Claude จดไว้ สาเหตุคือระบบรู้จำเสียงภาษาไทยส่งผลลัพธ์ชั่วคราวมา แล้วเริ่มนับใหม่หลังหยุดพูด ข้อความก่อนหน้าเลยถูกเขียนทับ วิธีแก้คือเก็บประโยคที่จบแล้วไว้ก่อน เก็บเสียงย้อนหลังประมาณ 65 วินาทีเผื่อส่งซ้ำ และถ้าถอดสดไม่ได้ ก็ยังอัดไฟล์ต่อแล้วถอดทีหลังจากไฟล์ ผมไม่ได้เป็นคนหาสาเหตุนี้เอง ผมแค่รู้ว่ามันผิดเพราะลองใช้

2. โลโก้ "m" ไปทับปุ่ม New note

ผมสั่งให้ "ปรับหน้าแรกให้ awesome มี hero section แบบแอปโน้ตดีๆ" Claude ทำการ์ดต้อนรับขนาดใหญ่ให้ พอผมลองบน iPad จริง โลโก้ตัว m ใหญ่เกินไปจนไปทับปุ่ม New note กับ Scan slides ผมส่งข้อความไปว่า "hero card logo m is cover button" แล้วมันก็จัดเลย์เอาต์ใหม่ให้ปุ่มเรียงลงมาเมื่อจอแคบ และซ่อนโลโก้เมื่อพื้นที่ไม่พอ

3. ซิงก์ iCloud ที่ซิงก์ไม่ไป

ผมขอให้ "บันทึกขึ้น cloud และ sync กับเครื่องอื่นใน ecosystem เดียวกัน" ตัวอย่าง iPhone กับ iPad พอเปิดใช้ แอปบอกว่ากำลังซิงก์ แต่โน้ตจากสองเครื่องไม่ตรงกัน ผมถามกลับว่า "ทำไมไม่ sync fix it" แล้วถามต่อว่าซิงก์ทุกกี่นาที กดดึงเองได้ไหม และอยากเห็นความคืบหน้าเป็นรายการ

Claude ปรับโมเดลข้อมูลให้เข้ากับ CloudKit ย้ายรูปและเสียงไปเก็บแบบที่ซิงก์ได้ และเพิ่มปุ่ม Sync now กับรายการกิจกรรมซิงก์ล่าสุดในหน้า Settings ตอนทดสอบผมเชื่อม iPad ด้วยสาย USB ให้มันอ่านล็อกจากเครื่องจริง จนเห็นว่าสองเครื่องนำเข้าและส่งข้อมูลถึงกันภายในไม่กี่วินาที การซิงก์ทำงานเมื่อมีสัญญาณแจ้งเตือนหรือเมื่อเปิดแอป ไม่ได้ตรวจทุกนาที

ส่งขึ้น App Store ให้ AI ทำทั้งกระบวนการ

คืนวันที่ 15 ต.ค. ผมสั่งสั้นๆ ว่า "upload it to app store which story and all image for me automate 100%" ผมอยากให้เรื่องเล่า ภาพหน้าจอ และข้อมูลทุกอย่างถูกกรอกให้เสร็จ Claude เขียนสคริปต์ที่สร้างหน้าเว็บของแอป ตั้งค่ารายการในระบบ App Store Connect และอัปโหลดภาพหน้าจอ ผมช่วยแค่ตอนที่ต้องกดเองในหน้าเว็บของ Apple

ไม่ได้ราบรื่นทีเดียว สคริปต์ตั้งเรทอายุไม่ผ่าน ตอบกลับมา 409 อยู่หลายรอบ ผมรันซ้ำจนผ่าน อีกเรื่องคือไอคอนแอปที่หายไปจากหน้ารายการ ผมถามว่า "why it not have app icon on appstore connect" และอีกครั้งที่ช่อง Header กับ Search Results ว่างอยู่ ผมก็สั่งให้ทำภาพขึ้นมาเอง สุดท้ายผมขอให้ Claude จดขั้นตอนทั้งหมดเป็น skill เพื่อเอาไปใช้กับแอปอื่นต่อได้

หลังจากนั้น

ประวัติ git ในโปรเจกต์มีแค่ 6 commit ตอนที่ผมอัปโหลดขึ้น GitHub (20 ต.ค.) เพราะโปรเจกต์ไม่ได้ใช้ git มาก่อน แต่เห็นงานที่ตามมา วันที่ 21 ต.ค. แก้บั๊กที่ลายมือถูกบันทึกผิดหน้า กับการเพิ่มหน้าที่กระตุก จากนั้นเพิ่มปุ่มเลี้ยงกาแฟ (tip jar) เป็นของที่ซื้อได้สามระดับ ชื่อ coffee, lunch และ dinner แล้วขยับเวอร์ชันเป็น 1.3.0 พร้อมสคริปต์แนบบิลด์และส่งรายการ tip ให้ Apple

ที่ผมได้เรียนรู้จากแอปนี้ บั๊กที่ผมแจ้งซ้ำสามรอบ (ถอดเสียงหาย) มักเป็นของที่ต้องลองกับเครื่องจริงและเสียงจริง ในโปรแกรมจำลองมันไม่เกิด ถ้าจะสั่ง AI ทำแอปแบบนี้ เตรียมเครื่องจริงไว้ลอง และบอกให้ชัดว่า "เจออะไร" มากกว่า "ผิด"
