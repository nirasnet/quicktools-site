อยากทำงานต่อบน Mac จาก iPad ชั้นบน เลยให้ AI ทำ Mac Remote

เรื่องของ Mac Remote แอป iPad ที่คุม Mac ผ่าน VNC สร้างด้วย Claude Code จอดำ ล็อกอิน 38 วินาที และบั๊กแตะแล้วเป็นคลิกขวา พร้อม prompt จริง

โดย 9M4ck · มือใหม่

สิ่งที่คุณจะได้

  • ทำไมอยากเข้าถึง job ในเทอร์มินัลที่รันค้างบน Mac จาก iPad
  • บั๊กจริงสามข้อ: จอดำ ล็อกอินช้า 38 วินาที และแตะแล้วกลายเป็นคลิกขวา
  • prompt จริงหกข้อความ และวิธีใช้นอกบ้านอย่างปลอดภัย
ในหน้านี้ภายในวันเดียว: จากประโยคเดียวเป็นแอปที่ build ผ่านบั๊กที่ 1: จอดำ (และคำตอบที่ผิดไปหนึ่งรอบ)บั๊กที่ 2: เชื่อมต่อช้ามากบั๊กที่ 3: แตะแล้วเด้งเมนูคลิกขวาใช้นอกบ้านได้ไหมท่าทางการใช้งานprompt ที่ผมใช้จริง

เรื่องนี้เริ่มจากบ้านสองชั้น ผมเปิดงานทิ้งไว้บน MacBook ชั้นหนึ่ง มี job ในเทอร์มินัลที่ยังรันอยู่ แต่ตัวผมขึ้นมานั่งชั้นสอง และมี iPad อยู่ข้างตัว ผมแค่อยากทำงานต่อจากตรงนั้นโดยไม่ต้องเดินลงไปทุกครั้ง

ผมเลยบอก Claude Code ตรงๆ ว่าอยากได้แอป iPad ที่รีโมตเข้า Mac ในเครือข่ายเดียวกัน ไม่ได้เลือกเทคโนโลยีให้ ไม่ได้เขียนโค้ดเอง แอปที่ได้ชื่อ Mac Remote

ยังไม่มีลิงก์ดาวน์โหลด ผมค้นใน App Store แล้วไม่พบแอปนี้ และโค้ดอยู่ใน GitHub แบบส่วนตัว บทความนี้เลยเป็นเรื่องเล่าอย่างเดียว ถ้าวันไหนขึ้นสโตร์ผมจะมาใส่ลิงก์

ภายในวันเดียว: จากประโยคเดียวเป็นแอปที่ build ผ่าน

prompt แรกเมื่อ 17 ต.ค. เวลา 15:02 สั้นมาก (อยู่ท้ายบทความ) ภายในสิบกว่านาที Claude ตรวจเครื่องผม เห็นว่า Screen Sharing ของ macOS เปิดอยู่แล้ว เลือกไลบรารี VNC ชื่อ RoyalVNCKit แล้วเขียนแอป SwiftUI ขึ้นมา มัน build ผ่านและทดสอบในซิมูเลเตอร์ ซึ่งเจอ MacBook ของผมในเครือข่ายเอง เวลา 15:14 รายงานว่าเสร็จ

แต่ทดสอบบน iPad จริงแล้วมันไม่เป็นอย่างนั้น

บั๊กที่ 1: จอดำ (และคำตอบที่ผิดไปหนึ่งรอบ)

ผมพิมพ์สั้นๆ ว่า "ตอนนี้รันบน iPad แล้วแต่จอดำ" Claude เดาสาเหตุแรกว่า Mac ส่งแต่ละพิกเซลมาพร้อมไบต์ที่ 4 เป็น 0 ไลบรารีเลยตีว่าโปร่งใส ภาพจึงมองไม่เห็น มันแก้โดยสร้างภาพเองและไม่สนไบต์นั้น แต่ผมลองแล้วจอยังดำ และ Xcode ขึ้นว่า paused พร้อมโค้ดแอสเซมบลีที่ผมแค่ copy ไปวางให้มันดู

จากบรรทัด __abort_with_payload ในส่วน dyld มันสรุปว่าไม่ใช่ปัญหาวาดภาพ แอปแครชตั้งแต่เปิด เพราะระบบโหลดไลบรารี RoyalVNCKit ไม่ได้ ตัวไลบรารีไม่เคยถูกใส่เข้าไปในแอปเลย แก้ด้วยการเติม embed: true ในไฟล์ project.yml บรรทัดเดียว หลังแก้ แอปเปิดค้างอยู่ได้ 6 วินาทีขึ้นไป ก่อนหน้านั้นแครชทันที ผมขอไอคอนไปในข้อความเดียวกัน ได้เป็นโน้ตบุ๊กสีขาวมีเครื่องหมาย >_ กับสัญลักษณ์ Wi-Fi สีเขียว บนพื้นน้ำเงิน ที่วาดด้วยสคริปต์ Swift

ข้อสังเกตจากตรงนี้ คำอธิบายแรกของ AI ฟังดูสมเหตุสมผลแต่ไม่ใช่สาเหตุจริง สิ่งที่ช่วยคือผมวาง log จริงจาก Xcode ให้มันดู ไม่ใช่เล่าอาการด้วยคำพูด

บั๊กที่ 2: เชื่อมต่อช้ามาก

จอขึ้นแล้ว แต่ผมถามว่า "ต่อนานมาก แต่สุดท้ายก็ต่อได้ แบบนี้ปกติไหม" Claude ตอบว่าไม่ปกติ ควรใช้ 1 ถึง 3 วินาที มันใส่ตัวจับเวลาไว้ในแอปแล้วอ่านผลจากบันทึก ได้ตัวเลขชัดๆ ว่า

  • หา Mac เจอใน 0.16 วินาที
  • เปิดการเชื่อมต่อและถึงหน้าล็อกอินใน 0.8 วินาที
  • จากล็อกอินถึงภาพแรก 38 วินาที

สาเหตุคือการล็อกอินด้วยชื่อผู้ใช้และรหัสผ่านของ Mac ใช้การแลกกุญแจ 4096 บิต ไลบรารีคำนวณด้วย Swift ธรรมดา และ Xcode ปุ่ม Run build เป็นโหมด Debug ที่ไม่ optimize มันลองจับเวลาบนเครื่อง Mac ได้ประมาณ 26 วินาทีในโหมด Debug เทียบกับ 0.8 วินาทีใน Release ผมไม่ได้คิดเรื่องนี้เองเลย แก้โดยตั้งให้ปุ่ม Run build เป็น Release ใน project.yml

บั๊กที่ 3: แตะแล้วเด้งเมนูคลิกขวา

อีกข้อความหนึ่งที่ผมเจอ: "ตอนแตะบน iPad มันไม่คลิก แต่ขึ้นเมนูเหมือนคลิกขวาจากเมาส์" ต้นเหตุมาจากฟีเจอร์ที่ AI เพิ่มเองเพื่อรองรับเมาส์จริง คือตัวจับการแตะที่ตั้งให้รับเฉพาะปุ่มขวา แต่ iOS ไม่สนตัวกรองปุ่มนี้เวลาใช้นิ้วแตะ มันเลยทำงานกับทุกการแตะและชนะการคลิกปกติ แก้ให้รับเฉพาะเมาส์จริงเท่านั้น

ตอนท้ายของ session นั้น Claude ติดตั้งแล้วบอกว่ายังไม่ได้ยืนยันเรื่องความเร็วและการแตะด้วยตัวเอง เพราะการผ่านหน้าล็อกอินต้องใช้รหัสผ่านของผม ซึ่งผมไม่ให้มัน ให้ผมลองบน iPad เองต่อ บันทึกที่ผมมีจบแค่ตรงนี้ ผมจึงไม่เขียนว่าทุกอย่างหายแล้วเรียบร้อย

ใช้นอกบ้านได้ไหม

เช้าวันรุ่งขึ้น (18 ต.ค.) ผมถามสั้นๆ ว่า "ต่อ Mac ผ่านอินเทอร์เน็ตได้ไหม" คำตอบที่ได้คือใช้ Tailscale ซึ่งสร้างเครือข่ายส่วนตัวแบบเข้ารหัสระหว่างอุปกรณ์ของเราเอง แอปไม่ต้องแก้อะไร แค่เพิ่มรายการใหม่โดยกรอกที่อยู่ของ Mac ในเครือข่ายนั้น ข้อควรรู้ที่มันบอก:

  • การค้นหา Mac อัตโนมัติใช้ได้เฉพาะตอนอยู่ใน Wi-Fi เดียวกัน เลยควรมีสองรายการ คือรายการที่แอปหาเจอเอง กับรายการสำหรับตอนอยู่นอกบ้าน
  • Tailscale ต้องเปิดค้างบน Mac และ Mac ต้องไม่หลับ
  • อย่าเปิดพอร์ต 5900 ที่เราเตอร์เพื่อเข้าตรงๆ เพราะจะเอาหน้าล็อกอินของ Mac ไปไว้บนอินเทอร์เน็ตเปล่าๆ ให้คนเดารหัสไม่หยุด
  • จอ Mac ของผมละเอียด 2560×1664 และส่งเต็มสี ที่บ้านไม่เป็นปัญหา แต่บนเน็ตมือถืออาจกระตุก มันเสนอว่าจะเพิ่มโหมดประหยัดแบนด์วิดท์ให้ แต่ผมไม่ได้สั่ง จึงยังไม่มี

ท่าทางการใช้งาน

จาก README ของโปรเจกต์ โหมดทัชแพดเป็นค่าเริ่มต้น ลากหนึ่งนิ้วเพื่อขยับตัวชี้ แตะเพื่อคลิก แตะสองนิ้วเพื่อคลิกขวา ลากสองนิ้วเพื่อเลื่อน บีบนิ้วเพื่อซูม และมีคีย์บอร์ดบนจอที่เพิ่มแถว esc, tab, ⌃ ⌥ ⌘ ⇧, ลูกศร กับ ⌃C ไว้ให้ ซึ่งมีประโยชน์มากสำหรับคนที่ใช้เทอร์มินัลเป็นหลักอย่างผม

ทำด้วย AI โค้ดทั้งหมดเขียนโดย Claude Code ผมเป็นคนบอกว่าอยากได้อะไร ทดสอบบน iPad ของตัวเอง และบอกว่าตรงไหนผิด ภาพประกอบบทความนี้เป็นแบนเนอร์ที่ทำจากไอคอนของแอป ผมไม่ได้ใช้ภาพหน้าจอ เพราะหน้าจอรีโมตจะเห็นหน้าจอ Mac ของผมจริง

prompt ที่ผมใช้จริง

ผมพิมพ์ทั้งหมดนี้เป็นภาษาอังกฤษแบบไม่ถูกไวยากรณ์ ปล่อยไว้ตามจริง มีแค่ตรงที่วาง log ที่ผมแทนด้วยวงเล็บเหลี่ยม ทั้งหมดนี้อยู่ในสองวัน (17-18 ต.ค.) และมีไม่กี่ข้อความจริงๆ

1. ข้อความแรก (17 ต.ค.)

i want to create ipad app which can remote to my macbook in same network , my goal is i want to continue my work which run on this mac like, terminal job , but i open it on mac on 1st floor but i keep ipad to 2nd floor and i want continue work

2. จอดำ

now it run on ipad but it black screen

3. ขอไอคอน และแจ้งว่า Xcode หยุดทำงาน

create icon for this app, it still black srreen and in xcode it sshow pause and show like debut [วาง log จาก Xcode]

4. เชื่อมต่อช้า

i connecting for a long time but it can connect in filnally is it normal?

5. แตะแล้วขึ้นเมนูคลิกขวา

when i tab on ipad it not click but it show menu like a right click from mouse

6. ใช้นอกบ้าน (18 ต.ค.)

can it connect to mac over internet
ถ้าจะลองทำแบบนี้ เปิด Screen Sharing ของ Mac ให้ใช้เฉพาะในเครือข่ายที่ไว้ใจ อย่าพิมพ์รหัสผ่านลงในแชทกับ AI ให้ใส่ในหน้าตั้งค่าของแอปเอง และถ้าจะใช้นอกบ้านให้ใช้เครือข่ายส่วนตัวอย่าง Tailscale แทนการเปิดพอร์ตที่เราเตอร์

เกี่ยวกับผู้เขียน

สวัสดีครับ ผม 9M4ck เป็นคุณพ่อที่ชอบลองของใหม่ โดยเฉพาะ AI ที่แค่พิมพ์บอกเป็นภาษาบ้าน ๆ แล้วมันทำของใช้ได้จริงให้ ผมไม่ได้เขียนโค้ดเอง ผมเปิดเพจ จับมือ AI เพราะเพื่อน ๆ ทักมาขอให้จับมือทำของที่ผมทำที่บ้าน เช่นทีวีของครอบครัว

ภาพถ่ายและภาพหน้าจอในบทความมาจากทีวี โทรศัพท์ และโปรเจกต์ของผมเอง ส่วนคลิปและเสียงบรรยายบน Facebook ทำด้วยเครื่องมือ AI บล็อกนี้เรียบเรียงขั้นตอนที่เป็นตัวหนังสือจากโพสต์ของผม ให้ทำตามได้ตามจังหวะของคุณ
