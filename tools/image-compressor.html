Image Compressor, Resizer & Converter

Shrink photos, resize them and convert between JPG, WebP and PNG. Compare file sizes before you download.

🔒 Runs in your browser: nothing is uploaded

How to make an image smaller

Drop in a photo, then try these in order: lower the quality to 70 to 85 (the difference is hard to see but the file is often 60 to 80 percent smaller), set a max width that matches where the image will be shown (for example 1600 px for a blog post), and choose WebP or JPG for photos. The panel shows the original and new size side by side so you can stop when it looks good.

Which format?

  • JPG: best for photos. Does not support transparency, so transparent areas become white.
  • WebP: usually smaller than JPG at the same look, and supports transparency. Supported by all current browsers.
  • PNG: lossless and good for screenshots, logos and text. The quality slider has no effect, but resizing still shrinks it.

Good to know

Re-saving a JPG always loses a little detail, so keep your original. Camera metadata (location, date) is removed in the new file because the image is redrawn, which is a handy side effect before sharing photos. Everything happens in your browser and nothing is uploaded.
