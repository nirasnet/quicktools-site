Text Case Converter

Convert text to UPPER, lower, Title, Sentence, camelCase, snake_case or kebab-case.

🔒 Runs in your browser: nothing is uploaded

Which case should I use?

  • UPPER / lower: emphasis, or normalising text before comparing it.
  • Title Case: headings and names. This tool capitalises every word; style guides differ on small words like "of" or "the".
  • Sentence case: normal prose, with only the first letter of each sentence capitalised.
  • camelCase: variable names in JavaScript and Java.
  • snake_case: Python and database column names.
  • kebab-case: URLs, CSS classes and file names.

Notes

The programming cases split on spaces, punctuation and existing camelCase boundaries, so "helloWorld example" becomes "hello_world_example". Everything runs in your browser.
