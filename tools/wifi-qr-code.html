Wi-Fi QR Code Generator

Make a QR code guests can scan to join your Wi-Fi without typing the password. Print it or save as PNG.

🔒 Runs in your browser: nothing is uploaded

How to use it

Enter your network name exactly as it appears on your phone, choose the security type (almost all home routers use WPA/WPA2/WPA3), and type the password. The code appears instantly. Print it and put it on the fridge, in a guest room or on the café table.

How guests join

On iPhone and most Android phones, open the camera and point it at the code, then tap the prompt to join. No typing and no spelling mistakes in a long password.

Privacy and safety

The code holds your network name and password as plain data, so anyone who can see the printed code can join your network. Share it only where you would be happy to give out the password, and consider using your router's separate guest network. The code is generated on your device and what you type is never sent anywhere.

Troubleshooting

  • If the phone cannot join, check upper and lower case in the password.
  • Tick Hidden network only if your router does not broadcast its name.
  • Special characters such as semicolons and colons are handled automatically.
