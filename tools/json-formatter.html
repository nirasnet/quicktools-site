JSON Formatter & Validator

Validate JSON, pretty-print it with indentation, or minify it. Errors show the position.

🔒 Runs in your browser: nothing is uploaded

What this tool does
It parses your text with the browser's built-in JSON parser. If it is valid, you get it back neatly indented (Format) or on one line (Minify). If not, you see the parser's error message, which usually points to the position of the problem.


Most common JSON mistakes
  • Trailing commas after the last item in an object or array.
  • Single quotes instead of double quotes around keys and strings.
  • Unquoted keys, e.g. {name: "x"} instead of {"name": "x"}.
  • Comments, which JSON does not allow.


Privacy
Parsing happens locally in your browser. Nothing you paste is sent to a server, so it is safe to check configuration snippets, though you should still avoid pasting live secrets anywhere.
