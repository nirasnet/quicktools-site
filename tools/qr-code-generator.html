QR Code Generator

Create a QR code for a link, Wi-Fi details or text and download it as a PNG. Custom colours, no sign-up.

🔒 Runs in your browser: nothing is uploaded

How to use it

Type or paste a web address, a phone number, an email link (mailto:name@example.com) or any text. The code updates as you type. Press Download PNG to save it and use it on flyers, menus, business cards or slides.

Wi-Fi codes

To let guests join your network, enter text in this exact form: WIFI:T:WPA;S:NetworkName;P:YourPassword;;. Most phone cameras then offer to connect.

Choosing colours and error correction

Keep strong contrast: a dark dot colour on a light background scans best, and an inverted (light on dark) code may fail on some readers. Higher error correction lets the code survive scratches or a logo placed on top, but makes it denser. Medium is right for most uses.

Tips before printing

  • Always test the code with a phone before printing many copies.
  • Print it at least 2 cm (about 0.8 inch) wide.
  • Leave the blank border around the code; it is part of the standard.

The code is drawn locally in your browser. What you type is not sent anywhere, and the codes never expire because they hold the data directly.
