Pick the right type

  • Link or text: a web address, a menu page, plain text.
  • Email, phone, SMS, WhatsApp: opens a ready-to-send message or call when scanned.
  • Contact card: lets people save your name, company, phone, email and website in one scan.
  • Map location: opens the place in the map app (enter latitude and longitude).

For Wi-Fi sharing use the dedicated Wi-Fi QR Code Generator.

Style it, but keep it scannable

Square dots are the most reliable. Rounded and dotted styles look friendlier but scan slightly less easily, so test them. Keep strong contrast with a dark code on a light background, and keep the quiet border (blank margin) of at least 2 to 4 modules. A logo covers part of the code, so the tool automatically uses the highest error correction; keep the logo at 20 percent or less.

PNG or SVG?

PNG is right for screens and everyday printing (choose 1024 or 2048 px for print). SVG is a vector file that stays sharp at any size, ideal for signs, packaging and professional printers.

Before printing

  • Always scan the final code with a phone.
  • Print it at least 2 cm (0.8 inch) wide.
  • The data is stored in the code itself, so codes never expire. Nothing you type is sent to any server.
