Base64 Encoder & Decoder

Encode text to Base64 or decode Base64 back to text, with full Unicode support.

What Base64 is
Base64 turns binary data into plain text made of 64 safe characters (A-Z, a-z, 0-9, + and /), with = padding at the end. It is used to embed data in JSON, emails, URLs and data URIs.


Base64 is not encryption
Anyone can decode it. Never use Base64 to hide passwords or secrets; it only changes how data is written, not who can read it.


Unicode and errors
Text is converted to UTF-8 bytes before encoding, so emoji and non-English characters round-trip correctly. If decoding fails, the input probably has missing padding, stray characters, or isn't Base64 at all. URL-safe Base64 (using - and _) must be converted back to + and / first.
