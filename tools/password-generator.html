Password Generator

Generate strong random passwords in your browser using a cryptographically secure source.

🔒 Runs in your browser: nothing is uploaded

What makes a password strong
Length matters most. Each extra character multiplies the number of possible passwords, so a random 16-character password is far harder to guess than a clever 8-character one. Randomness matters too: passwords built from names, dates or keyboard patterns are easy for attackers to try first.


How this generator works
It uses your browser's crypto.getRandomValues, the same secure source used for cryptographic keys, and picks characters without bias. It guarantees at least one character from each type you select, then shuffles. Nothing is sent anywhere or stored.


Good habits
  • Use a different password for every account, and keep them in a password manager.
  • Turn on two-factor authentication wherever it is offered.
  • Prefer length (16+) over fancy symbols if a site limits characters.
