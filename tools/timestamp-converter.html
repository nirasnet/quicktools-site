What a Unix timestamp is
A Unix timestamp counts the seconds since 1 January 1970 00:00:00 UTC, known as the Unix epoch. It is a compact, time-zone-free way for programs and databases to store a moment in time.


Seconds or milliseconds?
Many systems use seconds (10 digits today, such as 1760000000), while JavaScript and some APIs use milliseconds (13 digits). This tool treats very large values as milliseconds automatically.


Time zones
The timestamp itself has no time zone. The UTC line shows the universal time, and the Local line shows the same moment in your browser's time zone. When typing a date, add Z or an offset such as +07:00 to avoid ambiguity.


The year 2038 problem
Systems that store seconds in a signed 32-bit integer overflow on 19 January 2038. Most modern software uses 64-bit values and is not affected.
