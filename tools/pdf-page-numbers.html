Add Page Numbers to PDF

Number the pages of a PDF. Pick the format, position, start number, font, colour, and skip the cover page.

Numbering style

How to number PDF pages

  1. Drop in a PDF.
  2. Choose the format (plain number, "Page 3" or "3 / 20"), the position and the start number.
  3. Press the button to download the numbered copy. Your original stays unchanged.

Handy options

  • Skip the cover: tick the box so the first page has no number and numbering starts on page 2 with your start number.
  • Start number: begin at 0, 5 or any value when the document continues from another file.
  • Pages to number: enter a range such as 3- to leave the front matter unnumbered.

"Page 3 of 20" counts the pages that are numbered, plus your start offset. Text uses the standard PDF fonts and is added on top of the existing page. Everything runs in your browser and your file is never uploaded.
