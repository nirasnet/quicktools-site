Rotate PDF Pages

Turn all pages, or only the pages you choose, by 90, 180 or 270 degrees and save a corrected PDF.

🔒 Runs in your browser: nothing is uploaded

When you need it

Scanned documents and phone photos often come out sideways or upside down. Rotating them here fixes the page orientation for good, so the file opens the right way up in every viewer, not just in your own.

Rotating only some pages

Leave the page box empty to turn every page. To rotate selected pages, type numbers and ranges such as 2, 4-6. Pages you do not list stay as they are, which helps with mixed files where only a few scans are sideways.

Good to know

  • Rotation is saved as a page setting, so the text, images and quality are untouched.
  • Rotating twice adds up: pressing the button again on the same file turns the same pages another step.
  • Password-protected PDFs must be unlocked in the program that created them first.

The work happens in your browser and the file is never uploaded.
