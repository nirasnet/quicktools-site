Using the CSS
Copy the line and paste it into a stylesheet, for example .hero { background: linear-gradient(135deg, #6d5dfc 0%, #ec4899 100%); }. It works in every current browser. Add a plain colour before it as a fallback for very old browsers.


Types and angles
  • Linear: colours blend along a line. 0° goes from bottom to top, 90° left to right, 180° top to bottom, 135° diagonally from the top-left.
  • Radial: colours spread outwards from the centre.
  • Conic: colours sweep around the centre like a colour wheel; the angle sets where it starts.


Colour stops
Each stop is a colour at a position from 0 to 100 percent. Add up to six, drag the sliders to move them, or press Random for inspiration. Choose neighbouring hues (blue to purple, orange to pink) for smooth results; opposite hues can go muddy in the middle. Check that text on top of the gradient keeps enough contrast everywhere.


The PNG download makes a wallpaper or background at the size you choose, including phone, 4K and banner sizes.
