CSS Gradient Generator

Design linear or radial gradients, copy the CSS and download the result as a wallpaper PNG.

🔒 Runs in your browser: nothing is uploaded


  
Using the CSS
Copy the line and paste it into a stylesheet, for example .hero { background: linear-gradient(135deg, #6d5dfc, #ec4899); }. It works in every current browser with no prefixes. Add a plain colour before it (background: #6d5dfc;) as a fallback for very old browsers.


Angles
With a linear gradient, 0° goes from bottom to top, 90° from left to right, 180° from top to bottom and 135° runs diagonally from the top-left corner. A radial gradient spreads outwards from the centre, so the angle does not apply.


Making gradients look good
  • Choose neighbouring hues (blue to purple, orange to pink) for smooth results; opposite hues can go muddy in the middle.
  • Check that text on top of the gradient still has enough contrast with every part of it.
  • The PNG download makes a 1920×1080 wallpaper or presentation background.
