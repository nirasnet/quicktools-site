URL Encoder & Decoder

Percent-encode text for safe use in URLs, or decode percent-encoded text back to readable form.

What URL encoding is
URLs can only contain a limited set of characters. Everything else, such as spaces, accents, emoji and symbols like & or ?, is written as a percent sign followed by two hex digits. A space becomes %20 and the letter é becomes %C3%A9.


When to use it
  • Putting text inside a query string value, for example ?q=hello%20world.
  • Passing a full URL as a parameter of another URL.
  • Reading a link that is full of % codes.


Details
This tool uses the browser's encodeURIComponent, which encodes reserved characters like / ? & = so that the text is safe as a single parameter value. Do not use it on a complete URL you want to keep working, because it would encode the slashes and colon as well.
