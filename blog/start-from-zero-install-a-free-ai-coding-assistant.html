Start From Zero: Install an AI Coding Assistant on Your Computer (Free Options)

These guides come from Jubmue AI (จับมือ AI), a Thai page that teaches ordinary people to build useful things with AI, step by step, without writing code. Follow along on Facebook, YouTube or TikTok.

Many people get stuck at the very first step, so this guide comes before the projects. Each of the three assistants below is an app for Mac or Windows: download it, sign in, and you can start. You do not need to open a terminal or know how to code.

Option 1: Codex (from ChatGPT)

You can start with a free ChatGPT account. Go to chatgpt.com/codex, choose Download, then sign in.

Option 2: Antigravity (from Google)

The personal plan was free at the time of writing. Sign in with a Gmail account. Download it from antigravity.google; versions exist for Mac, Windows and Linux.

Option 3: Claude Code (from Anthropic)

This is the assistant the author uses every day and is strong on long tasks. It needs a paid Pro plan (roughly 17 to 20 US dollars a month when this was written). Details are at claude.com/product/claude-code. If you are new, try a free option first and upgrade only if you keep using it.

Prices and free allowances change. The details above were checked in October 2026, so confirm them on each official page before you sign up.

Your first instruction

  1. After installing, choose a work folder when the app asks.
  2. Type a request in plain language, in any language the assistant understands. For example: "Make a countdown web page to my child's birthday."
  3. If the assistant asks for permission before doing something, read it first and only then confirm.

That is all you need before the projects: an English vocabulary game for kids and kids mode on an Android TV. Not sure how to word your requests? Read 5 tips for telling an AI what to build.
