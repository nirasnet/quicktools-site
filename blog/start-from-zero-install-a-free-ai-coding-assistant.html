Start From Zero: Install an AI Assistant on Your Computer

Three assistants you can download and sign in to, which ones have a free start, and the first thing to type.

9MBy 9M4ck
5 min read · Beginner · Updated 22 Nov 2026

What you will get

  • Pick one of three assistants and install it
  • See which ones you can try for free
  • Type your very first request
On this pagePick oneYour first request

A lot of friends told me they got stuck at the very first step: installing the thing. So before any project, here is how to start. All three are normal apps for Mac or Windows. You download, sign in, and go. No terminal, no code.

Pick one

1

Codex

Free to start

From ChatGPT. A free ChatGPT account is enough to begin.

chatgpt.com/codex: Download, then sign in.

2

Antigravity

Free to start

From Google. The personal plan was free when I wrote this. Sign in with Gmail.

antigravity.google: Mac, Windows and Linux.

3

Claude Code

Paid plan

From Anthropic. This is the one I use every day, and it is strong on long jobs. It needs a Pro plan (about 17 to 20 US dollars a month).

claude.com/product/claude-code

If you are new, start with a free one. Upgrade later if you keep using it.

Check the price yourself. I looked at these pages in October 2026. Plans and free allowances change, so confirm on each official page before you sign up.

Your first request

  1. Install, then choose a work folder when the app asks.
  2. Type what you want in plain words. For example: "Make a countdown web page for my child's birthday."
  3. If the assistant asks permission to do something, read it first, then confirm.

That is all you need. Next, try the English word game for kids or kids mode on the TV. Not sure how to word your requests? Read my 5 tips.
