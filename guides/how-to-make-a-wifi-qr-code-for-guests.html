How to Make a Wi-Fi QR Code for Your Guests

Typing a long Wi-Fi password on a phone is slow and easy to get wrong. A QR code lets guests point their camera and connect in a couple of taps.

Step by step

  1. Open the Wi-Fi QR Code tool.
  2. Enter your network name (SSID) exactly as it appears, including capital letters.
  3. Choose the security type (usually WPA/WPA2) and enter the password.
  4. Download the image and print it, or place it on a card.

Where to put it

  • Near the entrance, on the fridge, or at a reception desk.
  • In a rental listing or welcome folder.
  • Print it large enough to scan from about 30 cm away.

Keep it safe

Anyone who sees the code can join the network. Consider a separate guest network if your router offers one, and change the password if the printed code is lost. The code is built in your browser; the password is never sent to any server.
