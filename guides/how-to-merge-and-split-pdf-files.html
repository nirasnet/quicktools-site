How to Merge and Split PDF Files Safely

Sending one tidy PDF is easier than attaching five. Likewise you often only need to share a few pages of a long document. Both jobs are simple if you know what to expect.

Merging

Put the files in the order you want the pages to appear, then combine them. Page content such as text and images is copied exactly. Links between pages and bookmarks may stop working because page numbers change, so check them in the finished file.

Extracting pages

Use ranges such as 1-3, 5, 8-. Only the pages you list are kept, and you can list them in a new order to rearrange a document.

Protect private documents

Many websites upload your file to a server to process it. For contracts, ID scans or medical letters it is safer to use a tool that runs in your browser, where the file never leaves your device. The Merge PDF and Split PDF tools on this site work that way.

If a file will not open

Password-protected PDFs must be unlocked in the program that created them first. Damaged files can sometimes be repaired by opening them in a PDF viewer and printing to a new PDF.
