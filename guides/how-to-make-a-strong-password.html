How to Make a Strong Password You Can Actually Use

A strong password is one that is hard for a computer to guess and that you only use on one site. Most account break-ins come from reused or leaked passwords, not from clever guessing of a good one.

Length beats complexity

Each extra character multiplies the number of guesses an attacker needs. A long passphrase of four or more unrelated words is both stronger and easier to remember than a short password full of symbols. Current guidance from standards bodies such as NIST favours length and checking against known leaked passwords over forcing odd character rules.

Use a different password for every site

When one site is breached, attackers try the same email and password on other services. A unique password per site limits the damage to a single account.

Use a password manager

Nobody can remember dozens of unique long passwords. A reputable password manager creates and stores them, so you only remember one strong master passphrase.

Turn on two-factor authentication

Two-factor authentication adds a second check, such as an app code or a security key. Even if your password leaks, the account stays protected. Prefer an authenticator app or security key over text messages where you can.

What to avoid

  • Names, birthdays and keyboard patterns like "qwerty123".
  • Small changes to an old password, such as adding a number.
  • Sharing passwords in chat or email.
