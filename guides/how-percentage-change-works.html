How Percentage Change Works (With Examples)

Percentage change tells you how much a value has grown or shrunk compared with where it started. It is used for prices, salaries, website traffic, exam scores and almost anything that changes over time.

The formula

Percentage change = (new value − old value) ÷ old value × 100. A positive result is an increase and a negative result is a decrease.

Worked examples

  • A price rises from 50 to 65: (65 − 50) ÷ 50 × 100 = +30%.
  • Monthly visitors fall from 2,000 to 1,500: (1,500 − 2,000) ÷ 2,000 × 100 = −25%.
  • A 20% discount on 80 saves 16, so the new price is 64.

Why a rise and a fall do not cancel out

If a price goes up 50% and then down 50%, you do not return to the start. Starting at 100: up 50% gives 150, and down 50% of 150 is 75. The second percentage is applied to a different base, so it removes more than the first added.

Percent versus percentage points

If an interest rate moves from 4% to 5%, it rose by 1 percentage point, which is a 25% increase in relative terms. News stories mix these up often, so check which one is meant.

When the starting value is zero

You cannot calculate a percentage change from zero because dividing by zero is undefined. Report the absolute change instead, for example "from 0 to 40 visitors".
